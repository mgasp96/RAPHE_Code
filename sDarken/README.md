# CalciMetrics – Publication Data & Code

This folder contains all data, code, and figures needed to reproduce the sDARKEN fluorescence imaging analysis.
It is self-contained: the notebooks can be run on any machine after installing the `calcimetrics` package from the `code/` folder.

## How to Run the Notebooks

### 1. Install the calcimetrics package

From within the `sDarken/` directory:

```bash
pip install -e code/
```

This installs `calcimetrics` and its dependencies (numpy, pandas, matplotlib, scipy, seaborn).

For the publication-ready plot style used in the notebooks, also install SciencePlots:

```bash
pip install SciencePlots
```

### 2. Open and run the notebooks

```bash
jupyter lab notebooks/
```

- **`02_darken_reanalysis.ipynb`** — Run all cells. Figures are saved to `figures/` automatically when `SAVE_FIGURES = True`.
- **`03_fusion_reanalysis.ipynb`** — Run all cells. Figures are saved to `figures/darken_fusion/` automatically.
- **`04_darken_reanalysis_diss.ipynb`** — Section 0 regenerates the `_cleaned.csv` files from the raw CSVs. Sections 1–5 run the full analysis and produce all figures.

## Contents Description

### Notebooks

All three notebooks implement the same analysis pipeline on three experimental paradigms:

| Notebook | Preparation | Recordings | Total ROIs |
|----------|-------------|------------|------------|
| `02_darken_reanalysis` | Acute brain slices | 725, 732, 734, 736 | 35 |
| `03_fusion_reanalysis` | iPSC fusion organoids | 870, 977 | 22 |
| `04_darken_reanalysis_diss` | Dissociated neurons | E2037, E2043, E2047, E2049, E2050, E2052 | 25 |

Each notebook produces: per-recording ROI overlays, mean ± SD traces, a combined heatmap, an event raster plot, and average event waveforms.

### Code

The `calcimetrics` package provides a modular pipeline for fluorescence imaging data exported from ImageJ/Fiji. The core classes are `Recording` (single session) and `Dataset` (collection of recordings with replicate awareness).

### Input Data

Input data are provided as Source Data with the paper and are not included in this repository; place them in `input_data/` following the structure above. Raw data are ImageJ Mean Grey Value exports (`Results_*.csv`). Each CSV contains one column per ROI plus a background ROI column. ROI sets (`.zip`) are the corresponding Fiji ROI manager files and can be re-opened in Fiji alongside the original microscopy data to inspect ROI placement.

## Image Analysis Methods

Regions of interest (ROIs) were drawn manually in ImageJ/Fiji around individual neurons, with one additional ROI designated as a background region. Mean grey values were extracted for each ROI across all frames and exported as CSV files.

Background fluorescence was subtracted from each ROI trace by subtracting the background ROI value frame-by-frame. Fluorescence changes were expressed as ΔF/F, where baseline fluorescence (F₀) was defined as the median fluorescence of each ROI across the full recording duration. Traces were inspected visually and ROIs exhibiting movement artefacts or flat signals were excluded.

Accepted traces were linearly detrended to remove slow baseline drift and subsequently smoothed with a Gaussian kernel (window = 5 frames, σ = 2.5 frames). Values were converted to % ΔF/F. All analysis steps were implemented in Python using a custom python package built on pandas, NumPy, and SciPy.
